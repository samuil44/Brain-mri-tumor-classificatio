# Brain MRI Tumor Classification Assistant

**Final Project**

This project is an AI-assisted Streamlit dashboard that analyzes brain MRI images and classifies each image into one of four classes:

- Glioma
- Meningioma
- Pituitary tumor
- No tumor

The dashboard also provides rule-based candidate-region localization when a tumor class is predicted. The system is intended to support physician review and does not replace clinical diagnosis.

## Final Classification System

The final classifier uses weighted soft voting to combine the complete probability outputs of three trained convolutional neural network models:

- EfficientNetV2S
- InceptionV3
- EfficientNetB0

### Final Ensemble Weights

| Model           | Weight |
|-----------------|--------|
| EfficientNetV2S | 5%     |
| InceptionV3     | 40%    |
| EfficientNetB0  | 55%    |

For every possible class, the dashboard calculates:

```
Final probability =
    (EfficientNetV2S probability × 0.05)
  + (InceptionV3 probability × 0.40)
  + (EfficientNetB0 probability × 0.55)
```

The class with the highest final combined probability is selected as the final prediction. This is not majority voting: the system combines all four probabilities generated by each model rather than simply counting the models' predicted labels.

## Dataset and Retraining

The original project dataset came from the Mendeley Brain Tumor MRI Dataset, which contains T1-weighted contrast-enhanced MRI images organized into the four project classes. The working images were prepared as grayscale images at a target size of 224 × 224 pixels.

The earlier ensemble achieved 91.67% internal-test accuracy, but only 58.50% accuracy on an untouched external dataset. The difference of 33.17 percentage points indicated that the system performed well on data similar to its training data but did not generalize reliably to images from another source.

To improve generalization:

- 650 suitable external MRI images were added to the training data.
- These images were used for retraining only.
- A separate set of 278 external MRI images remained completely untouched and was used only for final external testing.
- The final internal test set contained 861 images.

After retraining, the ensemble achieved 86.99% internal-test accuracy and 84.89% untouched external-test accuracy. The internal–external gap therefore decreased from 33.17 to 2.10 percentage points, showing much more consistent performance across the two test sources.

## Final Evaluation Results

| Evaluation set            | Images | Accuracy |
|----------------------------|--------|----------|
| Internal Mendeley test set | 861    | 86.99%   |
| Untouched external test set| 278    | 84.89%   |

Logistic Regression and XGBoost stacking methods were also evaluated, but they did not provide a reliable improvement across both untouched test sets. Therefore, the weighted three-model ensemble was selected as the final classification method.

## Candidate-Region Localization

When the final prediction is a tumor class, localization functions embedded directly inside `app.py` perform a separate grayscale image analysis. The analysis uses visual properties such as intensity, local contrast, texture, edges, symmetry, component shape, and distance from the skull boundary to identify and rank up to three suspicious candidate regions.

-  **Red box:** first-ranked candidate
-  **Orange box:** second-ranked candidate
-  **Yellow box:** third-ranked candidate

When `notumor` is predicted, candidate-region detection is skipped and no boxes are displayed.

This localization stage:

- Is a rule-based OpenCV image-processing method, not a trained localization model.
- Runs after classification and does not affect the predicted class or confidence.
- Does not use ground-truth tumor masks.
- Shows candidate suspicious regions, not medically confirmed tumor boundaries.

The separate experimental `grayscale_detector.py` file is not required to run the final dashboard because the required localization functions are already included in `app.py`.

## Clinical Disclaimer

This AI prediction is intended to support clinical decision-making and should always be confirmed by a qualified radiologist or physician. The dashboard is an academic prototype and is not a certified medical device.
